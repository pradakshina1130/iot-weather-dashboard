🌦️ IoT Weather Dashboard Using ESP32 and Firebase

📌 Project Overview

The **IoT Weather Dashboard** is a web-based project designed to monitor and display weather-related sensor data using the ESP32 microcontroller and Firebase. It combines embedded systems, IoT communication, cloud database storage, and web development to provide an accessible dashboard for viewing weather information.

The project demonstrates how sensor data can be collected by an ESP32, sent to Firebase, and displayed through a web dashboard.

 🎯 Objectives

* Monitor weather-related parameters using an ESP32.
* Transfer sensor readings to Firebase over Wi-Fi.
* Store and retrieve data using a Firebase database.
* Display weather information through a web-based dashboard.
* Demonstrate the integration of embedded C/C++, IoT, cloud services, and web technologies.

🛠️ Technologies Used

* **ESP32:** Microcontroller for IoT data collection.
* **Embedded C/C++:** Programming the ESP32.
* **Firebase:** Cloud database for storing and retrieving sensor data.
* **HTML, CSS, and JavaScript:** Building the web dashboard.
* **GitHub:** Version control and project hosting.
* **GitHub Pages:** Hosting the dashboard website.

⚙️ System Architecture

1. **Data collection:** The ESP32 collects readings from connected weather sensors.
2. **Wi-Fi communication:** The ESP32 connects to a Wi-Fi network.
3. **Cloud storage:** Sensor readings are transmitted to Firebase.
4. **Web dashboard:** The website retrieves available data from Firebase.
5. **Data visualization:** The dashboard presents the readings in a user-friendly format.

✨ Key Features

* Web-based weather monitoring interface.
* Integration of ESP32 and Firebase.
* Cloud-based storage and retrieval of sensor readings.
* Accessible dashboard through a web browser.
* Suitable for learning IoT, embedded systems, and cloud-connected applications.

🔌 Hardware Requirements

* ESP32 development board.
* Compatible weather sensors, such as a DHT11 or DHT22, if used in the implementation.
* USB cable for programming and power.
* Wi-Fi connection.
* Breadboard and jumper wires, if required.

💻 Software Requirements

* Arduino IDE or another ESP32-compatible development environment.
* A Firebase project and configured database.
* A modern web browser.
* A GitHub account for repository hosting.
